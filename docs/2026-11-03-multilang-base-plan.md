## 一、哪些翻译，哪些不翻

文字都在 `src/experiments/2026-09-23-sonar-lake-3d/i18n.js`，共 94 条。

| 类别 | 例子 | 怎么做 |
|---|---|---|
| **要翻：手机外面我们自己写的字** | 面板（Device / View / Range / Depth…）、面板下的说明、拖船提示、湖岸提示、入场教程、分享对话框、Learn More、Shop {name}、“Get Accuphy Sonar App”、二维码说明、3D 停了的提示、“这个视图模拟里还没有” | 用店铺的说法；跟网站术语表一致 |
| **手机里面：照 App 自己的字** | 首页的视图格（Forward View、Down View、Live Combo…）、底部 Setting / Home / Map | App 有这种语言，就照抄 App 里的原字（法语就是这么做的）；App 没有这种语言，就留英文，跟客人买回去看到的一样 |
| **永远不翻** | PingLive、PingLive Mini、Accuphy Sonar App、Down Scan、CHIRP、App Store、Google Play、“ACCUPHY \| LAB” 标题、数字和单位、Live Ice | 原样 |
| **这次不做：营销版的锁** | 订阅卡、Unlock、邮箱、同意条款等 16 条（unlock_*、back_to_lake） | 属于营销版，拆版时再翻 |
| **不做：广告片** | — | #185 定了不出语言版广告片 |

**要先定的英文：** 入场教程的说明文字（三站各一句）现在还是占位的英文。翻 5 种语言之前，要 Jason 先定英文，不然改一次英文要重翻 5 遍。顺序：先翻其他文字，教程那几句等 Jason 定好英文再翻。

## 二、技术上要改的（Base 做）

1. Lab 认新语言：现在只认 `?lang=fr`，改成认 fr / de / nl / pl / 波罗的海那种。不认识的语言就用英文。
2. 字体补字母：现在的品牌字体只切了西欧字母。波兰语（ą ę ł ś ż…）和波罗的海语言（ā č ē š ž… / ą č ę ė į š ų ū ž）的字母会缺，要重切字体子集，多几 KB。
3. 欧洲语言默认用米，访客可以切换（10-28 规划里的建议）。英语、法语（加拿大）照旧用英尺。
4. 分享出去的链接带上语言，朋友打开看到的是同一种语言。
